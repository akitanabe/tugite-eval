## 変更点と判定

`grounded-processing-meaning`を追加し、既存構造gateとともに総合quality PASSの必須観測にする。
runnerの既存required_quality_observations機構を使用し、意味の自動採点器は追加しない。

judgeは図の主要ノード/注釈と本文（ある場合）が、その処理の役割・達成内容を伝えるかを読む。
変数に値を入れる/比較する/呼ぶ/返すという操作を日本語へ置き換えただけの主要説明は、事実が正しく
経路が明示されていてもsemantic観測はFAIL。概要だけに目的らしい語を足して相殺しない。
ただし識別子/式/値を禁止せず、コード対応や重要な条件・確定境界を支える必要な記述として許す。
全ての末端ノードに別の意味解説を要求せず、図と説明の統合や、意味を伝える図だけの簡潔な出力を許す。
新しい説明agent・固定語数/比率・語句禁止・特定言い換えへの一致は不要。

目的/達成内容はコード・提供資料に根拠のある機能上の意味。作者がそう設計した歴史的理由、未提供の業務目的、
呼出しが実装していない保証を創作することではない。欠落依存では既知部分の役割を評価し、未知内部の意味を強制しない。
根拠ない意図で意味らしく装う説明は不合格。構造/正確性/意味は独立に記録する。
